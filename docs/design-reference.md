# Интерфейс Done: ориентиры и размеры

Done — самостоятельный концепт продукта для PM/продактов, не официальный продукт Notion.

Изучены официальные материалы Notion о [боковой панели](https://www.notion.com/help/navigate-with-the-sidebar), [layouts](https://www.notion.com/help/layouts), [задачах и зависимостях](https://www.notion.com/help/tasks-and-dependencies) и [обновлениях продукта](https://www.notion.com/releases), а также предоставленный пользователем скриншот. Статичный скриншот позволяет сопоставить плотность, цвета и иерархию; точные длительности анимаций Notion по нему не измерялись.

## Принятые значения

| Элемент                | Done                                                                   |
| ---------------------- | ---------------------------------------------------------------------- |
| Боковая панель         | тёплый фон #f8f7f5, выбранная строка #eeedeb                           |
| Строка навигации       | 32 px, текст 14 px, иконка 18 px                                       |
| Действия при наведении | появление за 100 ms; доступны также при фокусе с клавиатуры            |
| Верхняя панель         | компактные хлебные крошки и действия                                   |
| Заголовок проекта      | 32 px, иконка 40 px; без обложки                                       |
| Поля страницы          | 40 px на широком экране, 16 px на узком                                |
| Переход раздела        | мгновенная смена содержимого без полупрозрачного промежуточного экрана |
| Логотип приветствия    | поле 48 × 48 px, видимый знак около 40 px                              |
| Обычные кнопки         | 32 px; форма авторизации 40 px                                         |

Это выбранные токены реализации, а не заявленные официальные размеры Notion. На мобильном боковая панель открывается поверх содержимого. Эмодзи используют цветной системный emoji-шрифт без пониженной прозрачности. Настройка reduced motion отключает декоративное движение.

## Приветствие и бренд

Восстановлена центральная композиция приветствия: один логотип, заголовок, описание и «Начать». Форма входа/регистрации открывается следующим шагом. Нет второй колонки с повторным знаком. Имя, email и название пространства переживают возврат и перезагрузку вкладки; пароль в черновик не сохраняется.

Итоговый знак — чёрно-белый бумажный блок с жирной D. По последней правке пользователя он заменяет тонкие сложенные плоскости. Файл: `public/brand/done-mark.png`; используется также как favicon. Сгенерирован встроенным ImageGen с прозрачным фоном; в тёмной теме инвертируется.

Промпт итогового изображения: “One final square app logo for Done, a project-management sister-product concept in Notion's bold black-and-white visual language. A single sturdy white paper block with thick black squared frame, a tiny offset top/right depth edge, and a very bold black slab-serif D, never N or a checkmark. Nearly frontal, crisp optical weight, legible at 24 pixels, stroke about 7% of width. Transparent outside the white block, 5% padding. No hairlines, gray, gradients, shadow, texture, wordmark or extra designs.”
